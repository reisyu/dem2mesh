# GML地形データ処理スクリプト (Grasshopper/Rhino)

国土地理院のGML形式地形データを読み込み、平面直角座標系（JGD2011）に変換してRhinocerosの3Dメッシュを生成するGrasshopperスクリプトです。

## 概要

このスクリプトは、日本の測量計算規則に準拠した高精度な座標変換を実装しており、国土地理院が提供する標高データ（DEM）を建築・土木・GIS分野で活用できる形式に変換します。

### 主な機能

- **GML形式データの読み込み**: 国土地理院の標準形式に対応
- **高精度座標変換**: 平面直角座標系（JGD2011）への変換
  - 3次展開（高速モード）
  - 6次展開（標準/高精度モード）
- **自動ゾーン検出**: 緯度経度から最適な平面直角座標系ゾーンを自動選択
- **補間オプション**: バイリニア補間による高品質メッシュ生成
- **範囲クリッピング**: 指定領域の抽出が可能
- **サンプリング制御**: データ量の調整が可能

## パラメータ

### 入力パラメータ

| パラメータ名 | 型 | 説明 |
|------------|-----|------|
| `xml_data` | string | GML形式のXMLデータ（必須） |
| `jgd_zone` | int | 平面直角座標系のゾーン番号（1-19）。0以下で自動検出 |
| `sample_step` | int | サンプリングステップ（1以上）。大きいほど粗くなる |
| `target_point` | Point3d | クリッピング中心点（Unsetでクリッピングなし） |
| `size` | double | クリッピング範囲のサイズ（メートル単位） |
| `mode` | int | 処理モード（0: 高速, 1: 標準, 2: 高精度） |

### 出力パラメータ

| パラメータ名 | 型 | 説明 |
|------------|-----|------|
| `info` | List<string> | 処理情報（範囲、ゾーン、設定など） |
| `output_mesh` | Mesh | 生成された3Dメッシュ |

## 処理モード

### モード 0: 高速モード
- **座標変換**: 3次展開
- **高さ取得**: 最近傍点
- **用途**: プレビュー、大規模データの初期確認

### モード 1: 標準モード
- **座標変換**: 6次展開（高精度）
- **高さ取得**: 最近傍点
- **用途**: 一般的な用途、精度と速度のバランス

### モード 2: 高精度モード
- **座標変換**: 6次展開（高精度）
- **高さ取得**: バイリニア補間
- **用途**: 詳細な地形解析、プレゼンテーション

## 使用例

### 基本的な使用方法

```
1. GMLファイルをテキストとして読み込み
2. xml_data パラメータに接続
3. mode を選択（通常は 1 または 2）
4. output_mesh から生成されたメッシュを取得
```

### ゾーン指定

```
東京付近: jgd_zone = 9
大阪付近: jgd_zone = 6
自動検出: jgd_zone = 0（またはマイナス値）
```

### 範囲クリッピング

```
target_point: クリッピングしたい中心の座標（平面直角座標系）
size: クリッピング範囲（例: 1000 で 1km四方）
```

## 技術仕様

### 座標系
- **入力**: 世界測地系（JGD2011）緯度経度
- **出力**: 平面直角座標系（JGD2011）X, Y座標（メートル単位）
- **楕円体**: GRS80
  - 長半径 a = 6,378,137 m
  - 扁平率 f = 1/298.257222101

### 座標変換アルゴリズム
国土地理院「測量計算サイト」の計算方法に準拠した高精度なガウス・クリューゲル図法による変換を実装。

#### 6次展開（高精度モード）
- α1～α6 係数を使用
- 子午線弧長 S0 を A0～A6 で計算
- 精度: ミリメートルオーダー

#### 3次展開（高速モード）
- α1～α3 係数を使用
- 計算量を削減
- 精度: センチメートルオーダー

## パフォーマンス

- **並列処理**: Parallel.Forによる高速化
- **メモリ効率**: 無効点の削除と頂点の最適化
- **推奨データサイズ**: 10,000点以下（サンプリングで調整可能）

## データソース

### 国土地理院 基盤地図情報
- URL: https://fgd.gsi.go.jp/
- 形式: JPGIS（GML）形式
- データ種類: 数値標高モデル（5m, 10mメッシュなど）

### GMLデータの取得方法
1. 基盤地図情報ダウンロードサービスにアクセス
2. 対象地域を選択
3. 数値標高モデルを選択
4. ダウンロード・解凍してXMLファイルを取得

## エラー処理

### 主なエラーメッセージ

- `"Wait: xml_data が未入力です。"`: XMLデータが提供されていません
- `"Error: [詳細]"`: 解析エラーまたは変換エラー

### トラブルシューティング

1. **メッシュが生成されない**
   - XMLデータの形式を確認
   - sample_stepを小さくしてみる
   
2. **座標がおかしい**
   - jgd_zoneを手動で指定
   - 対象地域に適切なゾーンか確認

3. **処理が遅い**
   - sample_stepを大きくする
   - mode 0（高速モード）を使用
